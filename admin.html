💡 معلومة هامة: كيف تظهر الفيديوهات في موقعك فوراً دون الحاجة لـ GitHub؟
• سحابة Firebase: عند سحب أو حفظ الفيديوهات هنا، فإنها تُحفظ فوراً في قاعدة بيانات Google Firebase السحابية وتظهر لجميع زوار موقعك في ثوانٍ معدودة دون انتظار.
• مستودع GitHub: يحتفظ بالأكواد وملفات التصميم. الموقع الحي يقرأ من السحابة مباشرة. وإن كنت ترغب في حفظ نسخة مطابقة داخل كود GitHub، وفرنا لك زراً لتنزيل ملف videos.js المحدث بنقرة واحدة!
💡 ملاحظة: النظام مزود بمحرك استخراج ذكي يتكفل بجلب الفيديوهات والصور المصغرة تلقائياً حتى بدون إدخال المفتاح.

  1. افتح تبويب القواعد: Firebase Console Firestore Rules ↗
  2. انسخ الكود التالي واستبدل الكود الموجود به واضغط Publish (نشر):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
